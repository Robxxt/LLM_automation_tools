# LLM_automation_tools
Set of scripts to improve workflows using AI

## flutter_llm_symbolic_knowledge_graph_builder.py

This tool is designed for flutter projects. It captures the project structure, dependencies, models and classes.
 
 ### Instructions

Copy the `flutter_llm_symbolic_knowledge_graph_builder.py` file into your flutter project root directory and simply execute it. Then you will get a new file called `PROJECT_METADATA.json` which can be given to a new model to have a better understanding of your project.

 ```bash
chmod +x flutter_llm_symbolic_knowledge_graph_builder.py
./flutter_llm_symbolic_knowledge_graph_builder.py
```
